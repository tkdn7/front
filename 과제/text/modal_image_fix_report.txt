==============================================================
  모달 팝업 - 왼쪽 이미지 꽉 채움 수정 보고서
  수정 파일: front/과제/css/aw.css
==============================================================

──────────────────────────────────────────────
1. 수정 목적
──────────────────────────────────────────────
모달 팝업 창의 왼쪽 이미지 영역이 패딩에 의해 컨테이너와 분리되어
여백이 생기는 문제를 해결하고, 이미지가 border-radius와 동일한 곡률로
팝업 컨테이너에 완전히 녹아들도록 개선합니다.


──────────────────────────────────────────────
2. 수정 전 상태 (Before)
──────────────────────────────────────────────

.modal-inner {
   align-items: flex-start;  /* 세로 방향 상단 정렬 */
   gap: 32px;                /* 이미지·텍스트 간격 */
   padding: 48px 40px;       /* 전체 내부 여백 - 이미지도 padding 안쪽에 배치 */
   border-radius: 8px;
   overflow-y: auto;
}

.modal-image-area {
   flex: 0 0 50%;
   margin: 0;
   /* border-radius 없음 → 이미지가 모서리에서 들뜸 */
}

.modal-image-area img {
   width: 100%;
   height: auto;
   object-fit: contain;  /* 비율 유지, 남는 공간에 빈 여백 발생 */
}

.modal-text-area {
   flex: 1 1 0;
   overflow-y: auto;
   max-height: 70vh;
   color: var(--text);
   /* padding 없음 - modal-inner 의 전체 padding 에 의존 */
}

문제점:
- modal-inner 에 padding: 48px 40px 이 있어 이미지가 컨테이너 경계에
  닿지 못하고 사방에 여백이 생김
- object-fit: contain 이라 이미지 비율에 따라 좌우 또는 상하에
  빈 공간(letterbox)이 생김
- 이미지 영역에 border-radius 가 없어 컨테이너의 둥근 모서리 안에서
  이미지가 직각으로 튀어나와 보임


──────────────────────────────────────────────
3. 수정 내용 및 구현 방법 (After)
──────────────────────────────────────────────

▶ [1] .modal-inner — 패딩 제거 & align-items / overflow 변경

.modal-inner {
   display: flex;
   flex-direction: row;
   align-items: stretch;   /* ★ flex-start → stretch: 자식들이 동일한 높이로 늘어남 */
   gap: 0;                 /* ★ 32px → 0: 이미지가 텍스트에 붙도록 간격 제거 */
   padding: 0;             /* ★ 48px 40px → 0: 이미지가 컨테이너 경계까지 닿도록 여백 제거 */
   border-radius: 8px;
   overflow: hidden;       /* ★ overflow-y: auto → overflow: hidden
                               border-radius 안쪽으로 자식 이미지를 클리핑 */
   /* 나머지 속성 동일 유지 */
}

  - align-items: stretch 로 변경하면 .modal-image-area 가 modal-inner 의
    전체 높이에 맞게 자동으로 늘어납니다.
  - gap: 0 / padding: 0 으로 이미지를 컨테이너 왼쪽 경계에 밀착시킵니다.
  - overflow: hidden 은 border-radius 의 둥근 모서리가 이미지 모서리를
    실제로 잘라내도록(clip) 합니다. 이 속성이 없으면 이미지가 radius 를
    벗어나 직각으로 삐져나옵니다.


▶ [2] .modal-image-area — radius 및 overflow 추가

.modal-image-area {
   flex: 0 0 50%;
   margin: 0;
   border-radius: 8px 0 0 8px;  /* ★ 왼쪽 두 모서리만 modal-inner 와 동일한 8px */
   overflow: hidden;             /* ★ 이미지가 radius 밖으로 삐져나오지 않도록 클리핑 */
}

  - border-radius: 8px 0 0 8px 는 CSS 순서 "top-left top-right bottom-right bottom-left"
    이므로 컨테이너 왼쪽(이미지 측) 두 모서리만 8px, 오른쪽(텍스트와 맞닿는 면)은 0.
  - 이 값은 modal-inner 의 border-radius: 8px 와 정확히 일치하여
    이미지가 팝업 컨테이너에 완전히 녹아드는 효과를 냅니다.


▶ [3] .modal-image-area img — 이미지 채움 방식 변경

.modal-image-area img {
   display: block;
   width: 100%;
   height: 100%;         /* ★ height: auto → 100%: 부모(modal-image-area) 전체 높이 채움 */
   object-fit: cover;    /* ★ contain → cover: 빈 여백 없이 영역을 완전히 채움 */
}

  - height: 100% 로 설정해야 align-items: stretch 로 늘어난 부모 높이를 꽉 채웁니다.
  - object-fit: cover 는 이미지 비율을 유지하면서 영역을 완전히 채우며,
    넘치는 부분은 중앙 기준으로 잘라냅니다(letterbox 여백 없음).


▶ [4] .modal-text-area — padding 이동

.modal-text-area {
   flex: 1 1 0;
   display: flex;
   flex-direction: column;
   gap: 16px;
   overflow-y: auto;
   max-height: 85vh;           /* ★ 70vh → 85vh: modal-inner 높이와 통일 */
   color: var(--text);
   padding: 48px 40px;         /* ★ modal-inner 에서 이동: 텍스트 영역에만 여백 적용 */
   box-sizing: border-box;     /* ★ padding 이 너비에 포함되도록 */
}

  - modal-inner 에서 제거한 padding 을 텍스트 영역으로 옮겨
    텍스트는 기존과 동일한 여백을 유지합니다.
  - 이미지에는 여백이 없고, 텍스트에만 여백이 있는 구조입니다.


▶ [5] 반응형 (@media max-width: 640px) 수정

@media (max-width: 640px) {
   .modal-inner {
      flex-direction: column;
      /* padding: 0 유지 - 개별 영역에서 padding 처리 */
   }

   .modal-image-area {
      flex: none;
      width: 100%;
      height: 220px;              /* ★ 세로 배치 시 고정 높이 지정 */
      border-radius: 8px 8px 0 0; /* ★ 상단 두 모서리만 radius */
   }

   .modal-text-area {
      max-height: none;
      padding: 28px 20px;         /* ★ 모바일 여백 조정 */
   }
}

  - 세로 배치 시 이미지가 위(상단), 텍스트가 아래(하단)에 배치됩니다.
  - 이때 border-radius 는 8px 8px 0 0 (위 두 모서리만)으로 변경하여
    모바일에서도 팝업과 자연스럽게 어울립니다.

──────────────────────────────────────────────
5. 핵심 원리 정리
──────────────────────────────────────────────

  컨테이너(modal-inner)
  ┌──────────────────────────────────────┐  ← border-radius: 8px
  │  이미지 영역  │  텍스트 영역         │
  │  (50%)        │  padding: 48px 40px  │
  │  height: 100% │                      │
  │  object-fit:  │  Chapter 1: ...      │
  │  cover        │  본문 텍스트         │
  └──────────────────────────────────────┘
  ↑ border-radius: 8px 0 0 8px           ↑ 오른쪽은 radius 없음 (내부 경계)

  - modal-inner: overflow: hidden + border-radius → 이미지 모서리를 8px 곡률로 클리핑
  - modal-image-area: border-radius: 8px 0 0 8px → 직접 동일 곡률 적용 (이중 안전장치)
  - img: height: 100% + object-fit: cover → 여백 없이 영역 꽉 채움
